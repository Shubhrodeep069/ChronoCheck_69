# ChronoCheck - Time Tracking & Attendance System

A modern, full-featured web application for tracking work hours, managing attendance, and monitoring productivity. Built with TypeScript, React, and PostgreSQL.

## 🚀 Features

- **Real-time Time Tracking**: Start, stop, and pause timers for precise hour logging
- **Attendance Management**: Track daily attendance and generate reports
- **Productivity Dashboard**: Visualize work patterns and time allocation
- **Project Management**: Organize tasks by projects and categories
- **Reporting & Analytics**: Generate detailed time reports and insights
- **User Authentication**: Secure login and session management
- **Responsive Design**: Works seamlessly on desktop and mobile devices

## 🛠️ Tech Stack

- **Frontend**: TypeScript, React, CSS
- **Backend**: Node.js/TypeScript
- **Database**: PostgreSQL (PL/pgSQL)
- **Architecture**: Modern, scalable web application

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn
- PostgreSQL database

### Installation

1. Clone the repository
```bash
git clone https://github.com/Shubhrodeep069/ChronoCheck_69.git
cd ChronoCheck_69
```

2. Install dependencies
```bash
npm install
```

3. Set up environment variables
```bash
cp .env.example .env
# Update .env with your configuration
```

4. Start the development server
```bash
npm start
```

The application will be available at `http://localhost:3000`
